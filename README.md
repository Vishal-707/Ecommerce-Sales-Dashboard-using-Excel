# Ecommerce-Sales-Dashboard-using-Excel

The E-commerce Sales Dashboards project aimed to provide comprehensive insights into e-commerce sales performance through interactive and visually appealing dashboards developed using Excel. I analyzed sales trends, customer behavior, category-wise revenue, device usage, and city-wise performance. Used Complex parameters to drill down in worksheet and customization using filters and slicers. Created interactive dashboard to track and analyze online Sales Data
